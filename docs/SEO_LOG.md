## 週次リチュアル（所要10分）

毎週月曜。この順でやる。**5と6を飛ばすと、ただの数値倉庫になる。**

1. GSC 検索パフォーマンス → クエリ別・ページ別を見る（3か月ビュー、平均掲載順位ON）
2. 「定量記録」に1行追記（※`scripts/metrics/` の自動化が動いたら、この手作業は廃止して自動生成CSVを正とする）
3. 実SERPを1〜2クエリだけ目視（GSCの順位と、実際の見え方は違う）
4. 「施策・定性ログ」に観察を追記
5. **「検証待ち仮説」の期限が来たものを判定** → 結果を書き、仮説を閉じる
6. **効かなかったものは「効かなかったこと」に移す**（これを省くと同じ失敗を繰り返す）
